# SoulBot 自动助手

SoulBot 是一款 Android 端的 Soul 自动化辅助工具，帮助用户整理聊天上下文、管理个人资料，并通过自己配置的 AI 模型辅助生成回复。应用提供运行状态展示和人工停止入口，自动化过程应保持可监督。

**当前版本：2.2.3** · Android 8.0（API 26）及以上

## 主要功能

- 支持「星球与聊天」和「广场与私聊」两种自动化模式。
- 结合当前对话和近期上下文生成回复，减少脱离语境的机械回应。
- 支持配置多个兼容 OpenAI Chat Completions 的模型服务，并设置优先级。
- 可配置个人资料的公开范围。
- 提供联系人聊天记录、备份与恢复功能。
- 提供运行状态悬浮控制器、设备诊断和日志导出。
- 提供人工监督的回复回放与反馈工具。
- 采用统一的 Apple OS 风格界面体系：内页使用与首页同色系的浅蓝渐变画布和柔和光感层次，并统一标题、卡片、间距、按钮、输入框与顶部导航。
- 普通私聊采用**联系人级持久化 FIFO 队列**：每个联系人对应一个处理任务，按入队顺序逐个处理。
- 新一轮未读检查只识别当前可见的联系人页；不会因全局未读红点而逐页扫描整份联系人列表。
- 已进入队列但暂时不在当前视口的具体联系人，才会触发必要的页面定位；定位经过的其他联系人不会被批量加入队列。
- 联系人 FIFO 队列清空后，自动返回当前模式的空闲页面；同城私聊模式返回同城广场，不会因残留红点反复跳回联系人列表。
- 队列持久化任务状态，支持失败退避重试、应用重启恢复，以及发送结果不明确时的人工核验；进入私聊后才读取聊天内容并构建回复上下文。
- 过滤官方通知、系统通知等非普通私聊内容；非普通私聊的特殊流程继续使用原有事件队列。
- 同城广场识别头像附近的「活动中」「直播中」等状态，以及「正在热聊」「一键加入」等活动入口，在点击前跳过对应卡片。
- 同城广场限制头像点击目标，不向上触发整张动态卡片；点击后验证目标页面，无法确认主页时停止当前卡片处理并执行有限恢复。
- 提供应用内版本检查、更新说明、APK 下载与安全校验；新版本可在打开应用时自动提示。
- 联系人任务队列不保存消息正文、预览、消息时间或消息事件 Key；聊天历史仍由原有上下文、记忆和学习链路使用。

## 安装与开始使用

1. 前往 [GitHub Releases](https://github.com/zmsmao/soul-pilot/releases) 下载最新正式版本 APK。
2. 在 Android 设备上安装并打开 SoulBot。
3. 配置模型服务地址、模型名称和 API Key，并测试连接。
4. 按需填写个人资料和任务设置。
5. 授予无障碍服务与悬浮窗权限。
6. 打开 Soul，启动悬浮控制器，并在确认当前状态后开始任务。

详细步骤见 [Android 使用指南](android-app/README.md)。

## 系统要求

- Android 8.0（API 26）或更高版本。
- 已安装并登录 Soul。
- 可用的模型服务和网络连接。
- 无障碍服务与悬浮窗权限。

## 隐私与数据

SoulBot 需要通过 Android 无障碍服务读取 Soul 中可访问的页面内容。生成回复时，所选聊天上下文及已配置的资料可能会发送给用户选择的模型服务商，并可能产生费用。聊天记录、回放和诊断数据保存在设备本地；用户主动导出的文件可能包含聊天正文，请妥善保管。

## 版本与更新

版本变更见 [CHANGELOG.md](CHANGELOG.md)。当前 Android `versionName` 为 `2.2.3`，`versionCode` 为 `12`。应用会在打开首页时按 24 小时节流检查 GitHub 最新正式版，也可在「设置 → 版本更新」手动检查。下载的 APK 会校验 SHA-256、包名、版本与固定发布签名，再交由 Android 系统安装器完成安装确认。正式 APK 通过 GitHub Actions 构建，并使用固定发布签名。首次从此前的 Debug 测试包迁移到正式版本时，需要先备份数据、卸载 Debug 包，再安装正式包；之后使用同一发布签名的更新可直接覆盖安装。

## 项目说明

本项目依赖 Soul 客户端当前提供的无障碍页面结构和可见内容。客户端更新、设备后台管理策略或模型服务变化都可能影响运行效果。直播/活动卡片过滤依赖 Soul 暴露给无障碍服务的文本、描述和节点结构；不同客户端版本或卡片样式可能存在差异，无法识别或无法安全点击时应跳过，不应强行点击。请在使用过程中保留人工监督，并遵守聊天对象表达的意愿。
